## 1. 环境前置

| 组件 | 版本 | 校验 |
| :--- | :--- | :--- |

## 2. 安装

### 2.1 安装 cgc（editable 模式，方便边改边测）

```powershell
# 一次性：装 pipx
python -m pip install --user pipx
python -m pipx ensurepath
# 关闭再开 PowerShell 让 PATH 生效

# 把本仓库以 editable 模式装进独立 venv
pipx install --editable e:\claude-hub\CodeGraphContext

# 验证：cgc 应当指向本仓库源码
pipx runpip codegraphcontext show codegraphcontext | Select-String 'Editable project location'
# 期望：Editable project location: e:\claude-hub\CodeGraphContext
```

> editable 让源码改动立即生效。详细原理见 002 文档第 12 节。

### 2.2 安装 scip-dotnet

```powershell
dotnet tool install --global scip-dotnet
where.exe scip-dotnet                              # 应输出绝对路径
scip-dotnet --version                              # 应输出版本号
```

> 包名是 `scip-dotnet`（小写、连字符），由 Sourcegraph 发布。**`Microsoft.CodeAnalysis.ScipDotnet` 不存在**。

如果 `scip-dotnet --version` 提示需要 .NET 8 runtime：

```powershell
winget install Microsoft.DotNet.Runtime.8
```

## 3. 配置

```powershell
cgc config db kuzudb                               # 必须！硬编码默认是 falkordb，Windows 跑不起来
cgc config set SCIP_INDEXER true                   # 启用 SCIP
cgc config set SCIP_LANGUAGES csharp               # 限定 C#

cgc config show | Select-String DEFAULT_DATABASE,SCIP_INDEXER,SCIP_LANGUAGES
# 期望三行：
#   DEFAULT_DATABASE | kuzudb
#   SCIP_INDEXER     | true
#   SCIP_LANGUAGES   | csharp
```

## 4. 准备工程

`scip-dotnet` 走 Roslyn，必须能成功 restore + build：

```powershell
Push-Location F:\codingnet\FSAutoBuildTool
dotnet restore
dotnet build --no-restore                          # 修干净任何编译错误
Pop-Location
```

CGC 会自动找根目录第一个 `.sln`，找不到再递归找 `.csproj`（自动跳过 `bin` / `obj` / `node_modules` / `.git` 等）。

## 6. 验证图谱质量

```powershell
# 节点数
cgc query "MATCH (n) WHERE n.path CONTAINS 'FSAutoBuildTool' RETURN labels(n)[0] AS label, count(*) AS n ORDER BY n DESC"

# CALLS 边质量（Function-Function 应是主体）
cgc query "MATCH (a:Function)-[r:CALLS]->(b:Function) RETURN count(r) AS func_to_func"
cgc query "MATCH (a:File)-[r:CALLS]->(b:Function) RETURN count(r) AS file_to_func"
# 主推期望：func_to_func > 0、file_to_func 接近 0

# 类→方法归属
cgc query "MATCH (c:Class)-[:CONTAINS]->(f:Function) WHERE c.path CONTAINS 'FSAutoBuildTool' RETURN c.name AS class_name, count(f) AS methods ORDER BY methods DESC"
```

FSAutoBuildTool 实测参考值：

```
Function: 40, File: 8, Class: 7, Directory: 3, Repository: 1
func_to_func: 136, file_to_func: 0
Program: 14 methods, BuildHelper: 10, PersetConfig: 7, PatchHelper: 5, ServerBuilder: 4
```

## 7. 独立使用 —— `cgc` CLI

```powershell
# 列出已索引仓库
cgc list

# 找符号
cgc find name DoPerset                  # 精确匹配
cgc find pattern Build                  # 模糊
cgc find type class                     # 列所有类

# 调用关系
cgc analyze callers DoPerset            # 谁调用了 DoPerset
cgc analyze calls    DoPerset           # DoPerset 调用了谁
cgc analyze tree     IBuildStep         # 继承/实现树

# 复杂度 & 死代码
cgc analyze complexity --threshold 10
cgc analyze dead-code

# 直接 Cypher
cgc query "MATCH (c:Class {name:'PersetConfig'})-[:CONTAINS]->(f:Function) RETURN f.name ORDER BY f.line_number"
```

完整命令表：`@e:/claude-hub/CodeGraphContext/docs/CLI_COMPLETE_REFERENCE.md`。

## 8. 接入 Claude Code（MCP 模式）

Claude Code 的 MCP 配置有**两种作用域**，按你的需求选一种：

| 作用域 | 文件位置 | 启用时机 | 适合 |
| :--- | :--- | :--- | :--- |
| **用户级**（user-scope） | `%USERPROFILE%\.claude.json` | 任何工程打开 Claude Code 都启用 | 多工程都想要这个 MCP |
| **工程级**（project-scope） | `<project>\.mcp.json` | 只在打开此工程时启用 | 只给特定工程用；可入 git 团队共享 |

下面同时给出两种方式。仅对**本指南的 FSAutoBuildTool**而言，**推荐工程级**（方式 C）——避免把 SCIP / csharp 这套设置硬塞给你所有 Claude Code 会话。

### 方式 A：用户级 · 交互式向导

```powershell
cgc mcp setup
```

按向导：
1. 自动配置 IDE/CLI → `Y`
2. 选 IDE → `Claude code`
3. 数据库 → 直接回车（用默认 KuzuDB）

向导会写到 `%USERPROFILE%\.claude.json`。

### 方式 B：用户级 · 手动写 `~/.claude.json`

合并以下片段到 `%USERPROFILE%\.claude.json`（**不要覆盖**你已有的 `mcpServers`）：

```json
{
  "mcpServers": {
    "CodeGraphContext": {
      "command": "cgc",
      "args": ["mcp", "start"],
      "env": {
        "SCIP_INDEXER": "true",
        "SCIP_LANGUAGES": "csharp"
      },
      "disabled": false
    }
  }
}
```

### 方式 C：工程级 · `<project>\.mcp.json`（推荐给本指南）

在工程根目录新建 `F:\codingnet\FSAutoBuildTool\.mcp.json`：

```json
{
  "mcpServers": {
    "CodeGraphContext": {
      "command": "C:\\Users\\<you>\\.local\\bin\\cgc.exe",
      "args": ["mcp", "start"],
      "env": {
        "SCIP_INDEXER": "true",
        "SCIP_LANGUAGES": "csharp"
      }
    }
  }
}
```

- 用绝对路径填 `command`（Windows 上 Claude Code 子进程可能拿不到 pipx shim 的 PATH）。运行 `(Get-Command cgc).Source` 取你机器上的绝对路径。
- 首次启动 Claude Code 时会弹窗 `New MCP server detected: CodeGraphContext — Allow / Deny`，选 **Allow**。这个许可记在 `%USERPROFILE%\.claude.json` 里，下次不再问。
- `.mcp.json` 可以入 git，团队成员各自首次启动会被各自询问 approve。

### 验证 MCP 集成

1. **完全退出** Claude Code（任务栏右键 → Quit），重新打开。
2. 在对话里问：
   > 用 codegraphcontext 列出 FSAutoBuildTool 里谁调用了 DoPerset，并给出文件名和行号。
3. Claude Code 调用 MCP 工具，返回结果。设置面板的 「MCP servers」 里 `CodeGraphContext` 应显示 connected。

## 9. 一次性工作流（每台机器只做一次）

```powershell
# 安装
python -m pip install --user pipx
python -m pipx ensurepath
# 关闭再开 PowerShell

pipx install --editable e:\claude-hub\CodeGraphContext
dotnet tool install --global scip-dotnet

# 配置
cgc config db kuzudb
cgc config set SCIP_INDEXER true
cgc config set SCIP_LANGUAGES csharp

# 接 Claude Code
cgc mcp setup

# 索引 C# 工程
Push-Location F:\codingnet\FSAutoBuildTool
dotnet restore; dotnet build --no-restore
Pop-Location
cgc index F:\codingnet\FSAutoBuildTool

# 验证
cgc list
cgc analyze callers DoPerset
```

之后改 `e:\claude-hub\CodeGraphContext\src\` 下任何 `.py`，下次 `cgc` 调用立即生效。

## 10. 附录

### 10.1 关键路径

| 用途 | Windows 路径 |
| :--- | :--- |
| CGC 用户配置 | `%USERPROFILE%\.codegraphcontext\.env` |
| KuzuDB（默认嵌入式） | `%USERPROFILE%\.codegraphcontext\global\db\kuzudb` |
| 调试日志 | `%USERPROFILE%\mcp_debug.log` |
| Claude Code MCP 配置 | `%USERPROFILE%\.claude.json` |
| `dotnet tool` 全局工具 | `%USERPROFILE%\.dotnet\tools\` |
| editable pipx shim | `%USERPROFILE%\.local\bin\cgc.exe` |
| editable pipx venv | `%USERPROFILE%\pipx\venvs\codegraphcontext\` |
| 仓库源码（editable 直读） | `e:\claude-hub\CodeGraphContext\src\codegraphcontext\` |

### 10.2 关键环境变量

| 变量 | 来源 | 作用 |
| :--- | :--- | :--- |
| `SCIP_INDEXER` | `.env` 或 MCP `env` | `true` 才走 SCIP |
| `SCIP_LANGUAGES` | 同上 | 哪些语言走 SCIP |
| `DEFAULT_DATABASE` | `.env` | `kuzudb` / `neo4j` / `falkordb` |
| `NEO4J_URI` / `NEO4J_USERNAME` / `NEO4J_PASSWORD` | `.env` | 仅在用 Neo4j 时 |

### 10.3 切换 Neo4j（取代 KuzuDB）

```powershell
cgc neo4j setup            # 交互式输 URI / username / password
cgc config db neo4j
cgc index F:\codingnet\FSAutoBuildTool --force
# 切回：cgc config db kuzudb
```

### 10.4 重置一切

```powershell
cgc delete F:\codingnet\FSAutoBuildTool
# 终极：清掉所有 CGC 数据
Remove-Item -Recurse -Force "$env:USERPROFILE\.codegraphcontext"
```
